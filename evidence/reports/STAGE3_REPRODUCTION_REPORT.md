## 3. Master table (the one MATCH_1e-4 file)

`master_results_phase2_allfeatures.csv` has the same 12 rows in the same order. All text and integer columns are identical, including the model, feature set, imbalance handling, n_samples, n_features and TN/FP/FN/TP.

- **Largest numeric difference:** 4.996×10⁻¹⁰, in `precision_mean` of the FTTF_Dual_Head row.
- **Why it differs:** the saved original (26 Jan 2026) stores every metric rounded to 9 decimals, for example 0.908947453. The reproduction stores full precision, 0.9089474525522154. Rounding each reproduced value to 9 decimals gives the original file exactly.
  - None of the current scripts contains a rounding step, so the saved file was written by an earlier version or re-saved. The project does not record which.
- **Path columns differ by design:**
  - All baseline rows: `Heartseanse2.0\artifacts\` became `HeartSense_repro\runs\brfss\`.
  - FTTF_Dual_Head row: the original points to the January 2026 run folder (`phase2_fttf_dual_precbiased_gate\`). The reproduction points to the selected-features run reproduced in Stage 2, which is the run the published pipeline uses. Their metric values agree to the precision above.
